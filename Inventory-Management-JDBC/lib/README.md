# Inventory Management System (JDBC + MySQL)

Menu-driven Java JDBC application for the `Product` table in `retail_db`.

## Setup
1. Run the SQL script to create `retail_db` and the `Product` table.
2. Download MySQL Connector/J and put the jar in the `lib` folder.
3. Set your MySQL password in `InventoryManagement.java`.
4. Run `InventoryManagement.java`.
